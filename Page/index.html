Jarvis combine un modèle local, des outils métiers et une interface textuelle pour gérer les mails, le calendrier et les alarmes avec un coeur IA local, sans dépendre d'API LLM commerciales.

Problème actuel vs solution Jarvis

Problème actuel

  • Données envoyées vers des services externes
  • Coûts mensuels récurrents (abonnements SaaS)
  • Outils fragmentés: mail, agenda, rappels séparés
  • Peu de contrôle sur le comportement du modèle

Solution Jarvis

  • Traitement IA local avec Ollama
  • Projet open-source avec coût d'usage nul
  • Mail + agenda + alarmes dans une même interface
  • Orchestration métier personnalisée et explicable
01

Actions réelles

Envoi de mails, lecture de boîte, événements calendrier et alarmes locales.

02

Conversation naturelle

Une couche de dialogue locale conserve le contexte et garde le ton simple, direct et utile.

03

Architecture contrôlée

Le code orchestre les intentions, les états multi-tours et les intégrations Google / Ollama.
